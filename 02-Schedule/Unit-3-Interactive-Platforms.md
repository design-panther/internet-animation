# Unit 3 — Interactive & Alternative Platforms (Weeks 9–12)

Beyond the clip: Rive state machines make animation *respond*; Fancy Animation
Studio stages longer compositions in the browser; SVG and CSS handle motion
with no runtime at all. The unit's second thread is UCD II — putting your
motion in front of three real users and revising from what you learn. Ends
with the platform-comparison matrix and your final-project proposal.

- [[Week-09]] — Rive: Motion That Responds
- [[Week-10]] — Fancy Animation Studio Deep Dive
- [[Week-11]] — UCD II: Testing Motion with Users
- [[Week-12]] — Web-Native Motion: SVG & CSS · **final proposals due**

**Deliverables:** [[Project-3-Interactive-Sequence]] (Week 11, 50 pts) ·
final project proposal (Week 12).

**What "done" looks like:** an interactive or extended sequence you can defend
platform-choice for, tested with 3 users, with documented findings and one
revision you actually made.
