# Week 01 — Why Motion? The Landscape of Vector Animation

**Unit 1 — Foundations** · [[Unit-1-Foundations]] · Aug 17–Aug 21 *(dates track the live class calendar — check it)*

## This week

- Course intro; set up tool accounts (LottieFiles, Rive, Figma education, Fancy Animation Studio bookmark)
- A short history: Flash → Adobe Animate → Lottie/Rive — how vector animation moved from plugin players to native web formats
- Where vector animation lives today: UI microinteractions, apps, onboarding, explainer content
- Intro to User-Centered Design: motion with purpose vs. decoration

## Do

- Create your free accounts and confirm you can open each tool
- Start a running collection of animations you encounter in apps you actually use — auditing real motion is a habit this course leans on all semester

## Due

- Nothing formally due — but the **in-class exercises** begin: 14 are offered across the semester and any **7 count** (10 pts each; see [[Grading]]). Instructions are given in class.
