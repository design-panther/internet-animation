# The Toolbox

One page per tool the course uses — what it's for, where it appears in the
semester, and how to get set up. Deeper tutorials live in
[[Learning-Resources]], tagged by tool and week.

| Tool | Job in this course | Weeks | Cost |
|---|---|---|---|
| [[Illustrator-and-Figma]] | Drawing animation-ready vector artwork | 2+ | school license / free edu |
| [[After-Effects-and-Bodymovin]] | Industry vector animation + Lottie export | 5–8 | school license / free plugin |
| [[LottieFiles]] | Preview, host, test, and share Lottie files | 6+ | free tier |
| [[Rive]] | Interactive animation — state machines | 9, 11–16 | free tier |
| [[Fancy-Animation-Studio]] | Browser-based motion-path composition | 3, 10–16 | free |
| [[SVG-and-CSS]] | Web-native motion, no runtime | 12+ | free (it's the web) |

**Set up in Week 1:** LottieFiles account, Rive account, Figma education plan,
and bookmark Fancy Animation Studio. After Effects and Illustrator are on the
ET 206 lab machines.
