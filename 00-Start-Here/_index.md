# Welcome to Internet Animation

This is the course wiki for **GRFX1222 — Internet Animation** at Fairmont State
University: a 16-week hybrid course on **vector-based animation for the modern
web**. You'll learn foundational animation principles, produce animations in
current industry formats — **Lottie/dotLottie, SVG, and interactive runtimes
like Rive** — and practice **User-Centered Design**: defining the audience and
purpose for motion, prototyping, and usability-testing animations so that
motion serves users rather than decorates.

## How to use this wiki

- **[[01-Syllabus/_index|Syllabus]]** — the course contract: outcomes, grading, policies.
- **[[02-Schedule/_index|16-week schedule]]** — every week's topics, activities, and due dates. Each week has its own page.
- **Class Calendar** — the shared, live calendar. On the class platform it's editable by *everyone in the class* (use the ⧗ Class Calendar link in the sidebar): add study sessions, mark questions for critique day, fix dates. The public site shows a read-only copy.
- **[[03-Projects/_index|Projects & exercises]]** — the briefs for all four projects and both exercises, with what each is graded on.
- **[[Learning-Resources]]** — a rated library of verified tutorials, docs, videos, and tools, organized by unit and week. Free-first; every link checked.
- **[[05-Toolbox/_index|Toolbox]]** — one page per tool we use: Illustrator & Figma, After Effects + Bodymovin, LottieFiles, Rive, Fancy Animation Studio, and web-native SVG/CSS.
- **[[06-Reference/_index|Reference]]** — the glossary, the platform-comparison matrix, motion accessibility, and the UCD templates (motion brief, usability-test kit).
- **[[11-Blog/_index|Blog]]** — course essays that walk each unit's big ideas with curated resources.

## The one-sentence version of this course

> Animation on the modern web is **vector, tiny, and interactive** — and the
> difference between motion that helps and motion that annoys is **design for a
> user**, not decoration.

1. Read the [[01-Syllabus/_index|syllabus]].
