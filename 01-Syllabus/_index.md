## Course Description

This course introduces vector-based animation for the modern web and interactive
applications. Students learn foundational animation principles, produce
animations in current industry formats — including Lottie/dotLottie, SVG, and
interactive runtimes — and practice User-Centered Design: defining the audience
and purpose for motion, prototyping, and usability-testing animations so that
motion serves users rather than decorates.

## Course Outcomes

Upon successful completion of this course, students will be able to:

1. Skillfully produce vector-based interactions and animations (rich media) of a high level of difficulty.
2. Export, optimize, and implement animations in modern delivery formats (Lottie/dotLottie, SVG, embedded players).
3. Apply User-Centered Design methods — motion briefs, personas, and usability testing — to justify and refine animation decisions.
4. Design accessible motion, including reduced-motion alternatives and seizure-safe practices (WCAG).
5. Evaluate and select among animation platforms (Lottie, Rive, web-native CSS/SVG, video) based on project constraints.
6. Develop simple interactive animations using state-based authoring tools.
