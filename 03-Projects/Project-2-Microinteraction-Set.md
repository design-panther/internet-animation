# Project 2 — Microinteraction Set · 50 pts · due Week 8 (midterm critique)

Design and ship **3–5 related microinteractions** for one imagined (or real)
product — delivered as **working Lottie files** with a UCD rationale. Presented
at the midterm critique, where the question asked of every piece is:
**"Does the motion serve the persona?"**

## Deliverables

1. **3–5 Lottie files** from the microinteraction family: loading, success, error, empty state, pull-to-refresh, toggle, celebration — pick a coherent set for one product.
2. **A demo page or LottieFiles collection** where all of them play.
3. **The UCD rationale** — persona, the job of each animation, and your reduced-motion story ([[Motion-Accessibility]]): what does each animation do when `prefers-reduced-motion` is on?
4. **Optimization notes** — file sizes, and one thing you did to keep them small.

## Constraints

- Exported through the real pipeline (AE → Bodymovin → tested in a player). No video masquerading as Lottie.
- The set must read as one system: shared palette, shared timing vocabulary, shared personality.

## Grading (50 pts)

- 15 pts — animation craft (timing, easing, principle-informed detail)
- 10 pts — the set works as a system serving one persona
- 10 pts — technical delivery (working exports, sane file sizes, plays on two targets)
- 5 pts — reduced-motion / accessibility story
- 10 pts — critique participation (presenting yours, useful notes on others')
