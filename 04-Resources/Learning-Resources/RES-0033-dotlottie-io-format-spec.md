## What it covers
The official site for the dotLottie format, described as "the production format for Lottie" — a way to package multiple animations, assets, themes, and interactive state machines into a single open, compressed `.lottie` file that plays across platforms. Documents the specification, conversion/integration tools, cross-platform players, and compression benefits.

## What you'll learn
- What problem dotLottie solves versus a bare Lottie JSON file (bundling assets, themes, state machines, and compression into one file)
- The relationship between `.json` (classic Lottie) and `.lottie` (the packaged production format)
- What "interactive state machines" and theming mean in the context of a delivered animation
- Where to find cross-platform player integrations (web, iOS, Android, frameworks)
