## What it covers
A plain-language introduction to state machines written for designers who already think in states (hover, pressed, idle) without realizing it. It walks through the core vocabulary — states, transitions, listeners, data binding, and artboards — and argues that Rive removes the traditional design-to-developer hand-off by letting interactive logic live inside the animation file itself.

## What you'll learn
- What a "state" is in Rive (a timeline animation or blend) versus a transition between states
- How listeners (Pointer Enter, Pointer Exit, Click) fire logic without external code
- How data binding connects animation properties to live app data
- Why artboards act as reusable, self-contained components
- Why this model reframes animation as a responsive system rather than a fixed clip
