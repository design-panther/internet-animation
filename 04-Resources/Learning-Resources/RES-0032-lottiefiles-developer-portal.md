## What it covers
The official LottieFiles developer documentation homepage, framing Lottie as an open, MIT-licensed animation format for creating, packaging, and delivering animations, and organizing the docs into three areas: designing/exporting with LottieFiles Creator, integrating animations with dotLottie Runtimes, and understanding the underlying formats/specifications.

## What you'll learn
- What "Lottie" means as an ecosystem, not just a file format — creation tools, runtimes, and specs
- Why Lottie exists: open standard, no vendor lock-in, works across web/iOS/Android/desktop
- The high-level map of the docs site so students can self-navigate to deeper topics later
- How dotLottie Runtimes relate to the classic Lottie JSON format

## Notes
Use as the entry point for Week 6 — assign before the more specific supported-features and dotLottie-spec resources so students have the vocabulary and site map first.
