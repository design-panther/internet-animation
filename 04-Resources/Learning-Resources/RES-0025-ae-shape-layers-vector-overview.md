## What it covers
Adobe's official reference on shape layers in After Effects: how a shape layer is built from a path, stroke, and fill; the difference between parametric and Bezier shape paths; and how vector graphics stay resolution-independent (crisp at any size) compared to raster/pixel-based artwork.

## What you'll learn
- What a shape layer actually contains (path + stroke + fill) and how it differs from a raster (pixel) layer
- The difference between parametric shapes (rectangle, ellipse, star with adjustable numeric properties) and Bezier shapes drawn freehand
- Why vector graphics scale cleanly for responsive web/mobile delivery
- How importing vector artwork (e.g., from Illustrator) relates to native AE shape layers

## Notes
Core reference for Week 5: this is the foundational vocabulary (shape layer, path, fill, stroke) students need before drawing and animating shapes for later Lottie export. Read this before attempting the shape-layer exercises.
