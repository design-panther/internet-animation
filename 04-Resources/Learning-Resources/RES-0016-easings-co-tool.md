## What it covers
A free browser tool that lets you preview a library of common named easing curves (ease-in-quad, ease-out-cubic, ease-in-out-back, etc.) applied to real UI-style elements — buttons, cards, dots — so you can see how each curve actually feels in motion, then generate and copy its `cubic-bezier()` value.

## What you'll learn
- How dozens of standard easing curves differ from each other when applied to real elements, not just an abstract graph
- The naming convention (quad/cubic/quart/back/elastic, in/out/in-out) used across most animation tools
- How to pick an easing curve to match an intended feel (snappy vs. gentle vs. bouncy)
- How to export a curve's cubic-bezier coordinates for use in CSS, After Effects, or Rive
