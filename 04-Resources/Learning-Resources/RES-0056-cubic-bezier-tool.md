## What it covers
A widely used, free browser tool for visually designing and previewing CSS `cubic-bezier()` easing curves. Users drag two control-point handles on a graph to shape an acceleration/deceleration curve, preview the resulting motion live, compare against built-in curves (ease, ease-in-out, etc.), and copy the generated `cubic-bezier(...)` value or a shareable permalink.

## What you'll learn
- How the four numeric parameters of `cubic-bezier(x1, y1, x2, y2)` map to a visual curve shape
- How to design custom acceleration curves rather than relying on built-in ease presets
- How to preview timing before committing it to CSS, Rive, or After Effects keyframes
- How overshoot in a bezier curve produces a bouncy feel
