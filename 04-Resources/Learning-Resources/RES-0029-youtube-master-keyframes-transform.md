## What it covers
A step-by-step beginner video ("Lesson 9" of a broader series) that walks through keyframing the four core transform properties in After Effects — Position, Scale, Rotation, and Opacity — showing how to set keyframes and preview the resulting motion.

## What you'll learn
- How to reveal a layer's transform properties (shortcuts: A, P, S, R, T)
- How to set a keyframe by clicking the stopwatch icon and changing a value later in time
- How Position, Scale, Rotation, and Opacity keyframes combine to build a simple motion sequence
- A first practical rep before moving into curve refinement in the Graph Editor
