## What it covers
Rive's official documentation index for playing back state machines at runtime, defined as the logic layer that "controls interactive animations in a Rive file." It fans out into platform-specific implementation guides for Web/JavaScript, React, React Native, Flutter, Apple, Android, Unity, and Unreal — the step after building a state machine in the editor.

## What you'll learn
- How a state machine differs from a plain timeline animation at the code level
- How an app instantiates a Rive state machine and sets it to auto-play
- How boolean, number, and trigger inputs drive transitions between states from outside code
- Where to find the exact API for whichever runtime/framework you're targeting
- The conceptual link between the editor's visual graph and what ships to production
