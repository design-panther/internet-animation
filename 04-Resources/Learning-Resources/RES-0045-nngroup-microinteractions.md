## What it covers
NN/g's core definition of microinteractions as "trigger-feedback pairs," where the trigger is a user action or system-state change and the feedback is a small, contextual UI response. It covers user-initiated vs. system-initiated triggers, explains that good microinteractions communicate system status, prevent errors, and reinforce brand identity, and illustrates the ideas with real examples (Asana's celebratory animation, LinkedIn's pull-to-refresh, iOS shake-to-delete feedback, eBay's password validation). It also credits Dan Saffer's 2014 book *Microinteractions* as the concept's origin.

## What you'll learn
- The trigger → feedback model for analyzing any small UI moment
- The difference between user-initiated and system-initiated triggers
- Four functional roles microinteractions play: engagement, status, error prevention, branding
- How to spot and name microinteractions in products you already use
