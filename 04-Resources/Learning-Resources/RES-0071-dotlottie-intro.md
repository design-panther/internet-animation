## What it covers
The official introduction to dotLottie (`.lottie`), an open, IANA-registered file format that bundles one or more Lottie JSON animations plus their images, themes, and interactive state-machine definitions into a single compressed archive — positioned as the newer, more production-ready successor to raw Lottie JSON.

## What you'll learn
- Why `.lottie` files are typically far smaller than the equivalent `.json` Lottie file
- How dotLottie packages multiple animations, themes, and state machines together
- How dotLottie adds Rive-style interactivity (hover, click, scroll-driven state) to Lottie without custom JS
- Why a shared cross-platform renderer (ThorVG/WASM) matters for consistent playback
