## What it covers
The official LottieFiles developer portal explains that a Lottie is a JSON-based animation file format that ships animations "as easily as shipping static assets" — small files that render sharp on any device without pixelation. The portal indexes runtimes for web, React, Vue, Svelte, React Native, Flutter, iOS, and Android, plus code examples and use-case galleries (websites, in-app reactions, animated icons, games).

## What you'll learn
- What the Lottie format actually is and why it replaced GIF/APNG for UI animation
- Where Lottie animations are used in production today (apps, onboarding, icons, loaders)
- The breadth of platforms/frameworks a single Lottie file can ship to
- How Lottie connects back to After Effects (via the Bodymovin export pipeline covered later in the course)
