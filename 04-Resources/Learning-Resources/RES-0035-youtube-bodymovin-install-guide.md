## What it covers
A step-by-step video showing how to download and install the LottieFiles/Bodymovin extension into After Effects, then use it to export a composition as a Lottie JSON file — the practical, click-by-click counterpart to the written export docs.

## What you'll learn
- Where to get the LottieFiles/Bodymovin extension and how to install it into After Effects
- How to open the extension panel (Window > Extensions), select a composition, and render an export
- What the export destination and render settings look like in practice
- A visual reference for students installing the plugin for the first time on their own machines
