## What it covers
LottieFiles' official reference listing which After Effects features export correctly into Lottie and which do not. Supported items include shape layers, transform properties, masks, trim paths, basic text, and limited fill/stroke effects. Unsupported items include 3D layers, adjustment layers, complex expressions, most visual effects (blur, distortion, etc.), layer styles, and time-stretching.

## What you'll learn
- A concrete supported-vs-unsupported feature checklist to consult before starting an AE project meant for Lottie export
- Why certain "normal" AE techniques (3D layers, adjustment layers, most Effects-menu effects) will break or be silently dropped on export
- Which shape/text/transform techniques are safe defaults for Lottie-bound work
- How to plan a project's scope around the format's real constraints rather than discovering them after export
