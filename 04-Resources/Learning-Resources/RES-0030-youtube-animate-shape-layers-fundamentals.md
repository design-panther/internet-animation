## What it covers
Part of an "AE Fundamentals" series that focuses specifically on animating shape layers — connecting the static shape-building skills (path, fill, stroke) to actual motion by keyframing transform and shape properties together.

## What you'll learn
- How to move from a static shape layer to an animated one using keyframes
- Which shape-specific properties (e.g., path shape, trim paths, stroke width) can be animated in addition to standard transform properties
- Practical sequencing: build the shape first, then layer in motion
- A bridge concept between "drawing" week material and "animating" week material
