## What it covers
This is the official documentation for `@lottiefiles/dotlottie-web`, the core JavaScript player that renders both `.lottie` and plain Lottie JSON animations directly in the browser with no framework dependency. It walks through installation, rendering a first animation, playback controls, layout/theming, and links out to a full API reference, plus dedicated wrapper packages for React, Vue, Svelte, and Web Components.

## What you'll learn
- How to install and initialize the dotLottie web player via npm or CDN
- How to load and render a `.lottie` or `.json` animation in an HTML page
- How to control playback (play, pause, loop, speed, segments) via JavaScript
- Where to find framework-specific wrappers (React/Vue/Svelte/Web Components)
- How rendering options (Canvas2D/WebGL/WebGPU) affect performance

## Notes
Core Week 7 resource for "implementing Lottie on the web." This is the current, actively maintained successor to the older `lottie-player`, and is the recommended starting point for embedding animations in a course project site.
