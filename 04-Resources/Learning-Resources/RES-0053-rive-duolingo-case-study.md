## What it covers
A behind-the-scenes look at how Duolingo built its AI-powered Video Call feature around the character Lily using Rive's State Machine. The article describes how a small set of base animations (16) were blended into dozens of unique neutral movements (64+), how the team kept the final Rive file under 1 MB despite the complexity, and how animators and engineers collaborated through a "Riv Deliv" hand-off process.

## What you'll learn
- A concrete, real-world example of a state machine driving character behavior in production
- How modular animation blending reduces the number of assets an animator has to hand-author
- Why file size stayed small even as interactivity grew
- What a designer/engineer collaboration workflow looks like around a Rive file
- A quote from Duolingo's senior animator on why the state machine model mattered to the project
