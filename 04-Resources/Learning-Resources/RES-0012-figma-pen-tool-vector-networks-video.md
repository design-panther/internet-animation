## What it covers
An official Figma-produced screen-recorded tutorial demonstrating Pen tool basics and vector network editing directly in the Figma canvas — placing anchor points, dragging Bezier handles for curves, editing existing vector paths, and building simple shapes from scratch.

## What you'll learn
- A live, visual demonstration of everything described in RES-0010 (Vector Networks doc)
- How to enter and exit vector edit mode on an existing shape
- How to add, remove, and reposition points on a path after it's drawn
- Practical pacing/technique for drawing clean vector shapes quickly in Figma

## Notes
