## What it covers
Adobe's official reference on how After Effects interpolates values between keyframes, including the Graph Editor's Value Graph (shows a property's actual value over time) and Speed Graph (shows rate of change), and how Bezier direction handles let you fine-tune easing curves.

## What you'll learn
- The difference between the Value Graph and Speed Graph in the Graph Editor
- How to adjust Bezier direction handles to smooth or sharpen an animation curve
- Why spatial properties (like Position) default to speed graphs while others (like Opacity) default to value graphs
- How interpolation choices affect the timing/feel of an animation before it's ever exported

## Notes
Direct support for the Week 5 "graph editor" topic. Students should open the Graph Editor (Shift+F3) in their own project alongside this doc rather than reading it in isolation — the concepts only click when paired with a live timeline.
