## What it covers
MDN's introduction to SVG as an XML-based vector graphics language supported by all major browsers. It covers the basic anatomy of an SVG document (root `<svg>` element, shapes, grouping with `<g>`), and previews SVG's further capabilities — gradients, animation, filters, and JavaScript/DOM interactivity.

## What you'll learn
- What SVG is and how it differs from raster image formats
- The basic structure of an `<svg>` document and common shape elements
- Why SVG has a DOM interface (and what that means for styling/scripting/animating it)
- Where SVG fits among browser-supported vector specifications (1.1, 2.0, Tiny/Basic profiles)

## Notes
Foundational Week 12 reading on "SVG structure" before layering on CSS animation and the Web Animations API. Recommended before RES-0065 and RES-0067 for students without prior SVG exposure.
