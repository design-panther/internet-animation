## What it covers
An "awesome list" maintained by Rive's own GitHub org that catalogs articles, courses, videos, runtime docs, open-source example projects, and case studies (including Duolingo, Animade, and Struck) from across the Rive ecosystem. It links out to 50+ video tutorials, framework-specific guides (React, Flutter, SwiftUI, Unity), and open-source tools like the Rive Playground and Animation Viewer.

## What you'll learn
- Where to find worked, open-source example Rive projects to study or fork
- Framework-specific integration guides beyond plain web/JS
- Additional real-world case studies of interactive Rive animations
- A map of the broader Rive learning ecosystem (courses, videos, articles) beyond official docs
