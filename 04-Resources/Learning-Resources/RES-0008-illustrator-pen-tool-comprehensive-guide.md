## What it covers
A detailed, free walkthrough of Adobe Illustrator's Pen tool covering how to draw straight and curved (Bezier) paths, add/delete/convert anchor points, use the Scissors tool to cut paths, and set up Illustrator's Selection & Anchor Display preferences for cleaner control. Includes downloadable practice exercises.

## What you'll learn
- How Bezier curves and anchor-point handles actually work
- The rule of thumb: place anchor points where a curve changes direction, not mid-curve
- Keyboard shortcuts for fast, precise path drawing (P, Shift, Alt/Option, Cmd/Ctrl)
- Why fewer, well-placed anchor points make cleaner, more animation-ready artwork

## Notes
Core Week 2 reading for vector drawing foundations in Illustrator — do this before the in-class pen tool demo so students arrive with the vocabulary (anchor point, handle, Bezier segment) already in hand.
