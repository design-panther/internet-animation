## What it covers
This is Rive's official landing page for new users, framing the tool as a place where designers, animators, and developers "design, animate, and code in one place" without a separate hand-off step. It lays out the six-part Rive workflow — design, animate, make interactive, control with data, scripting, and publish anywhere — and links to a video quickstart that builds a complete interactive project.

## What you'll learn
- The overall shape of a Rive project from vector art to a shipped interactive file
- Why Rive treats animation as a system with logic, not just a rendered clip
- Where design work ends and interactivity/state logic begins
- Which runtimes and platforms a finished Rive file can target (web, React, Flutter, iOS/Android, game engines)
- Where to go next for hands-on tutorials

## Notes
Use this as the entry point for Week 9's Rive unit before opening the editor (a free tier is available at rive.app). Best read alongside the video quickstart linked on the page.
