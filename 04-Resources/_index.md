# Resources

The course's rated library of verified learning resources — tutorials, official
docs, videos, tools, and articles — organized by unit and week.

**Browse the full library: [[Learning-Resources]]**

Every entry is:

- **Verified** — the link was fetched and checked before it entered the library.
- **Free-first** — no paywalled courses, no commerce pages; official docs, YouTube, free articles, and free tiers.
- **Rated** — a 1–5 quality score with notes, so you can start from the best.
- **Tagged by week** — find everything for the week you're in (`week-05`, `unit-2`, …).

Found something great the library is missing? Tell the instructor or drop it on
the class whiteboard — good finds get added (and credited).
